# САПР БКС — автоматизированная трассировка бортовой кабельной сети вертолёта

Учебная мини-САПР: по трёхмерной модели отсеков вертолёта, списку блоков оборудования и схеме электрических соединений программа автоматически прокладывает кабели — обходя запрещённые зоны и соблюдая требования электромагнитной совместимости (ЭМС), — и выдаёт кабельный журнал, спецификацию и пошаговый протокол расчёта.

Подробнее в курсовой работе.

C# / .NET 8 / Windows Forms / SQLite. Курсовая работа по дисциплине «Разработка систем автоматизированного проектирования» (КНИТУ-КАИ, кафедра САПР).

## Постановка задачи

Маршрутная сеть отсеков задаётся графом `G = (V, E)`: вершины — узлы трасс (кабельные каналы, гермовводы, точки подключения блоков), рёбра — допустимые участки прокладки с геометрической длиной

```
d(i,j) = √((xi−xj)² + (yi−yj)² + (zi−zj)²)
```

Требуется для каждого соединения из схемы найти маршрут минимальной длины так, чтобы:

1. кабель не проходил через **запрещённые зоны** (топливные баки, горячие зоны двигателей, редукторы, проёмы дверей, ниши шасси);
2. в одном канале не оказались кабели **несовместимых типов** (силовой / информационный / сигнальный) — по матрице минимально допустимых расстояний `Dmin(α, β)`.

Критерий — суммарная длина сети `F = Σ L(k) → min`, где `L(k)` — длина кабеля вместе с подводками к блокам.

## Алгоритм

Модифицированный алгоритм Дейкстры, кабели прокладываются последовательно:

1. **Фильтрация зон.** Узел, попавший внутрь параллелепипеда зоны, удаляется из графа вместе со всеми инцидентными рёбрами.
2. **Учёт ЭМС.** Перед прокладкой очередного кабеля типа `T` вес ребра, уже занятого кабелем типа `T'` с `Dmin(T, T') > 0`, принимается равным ∞ — то есть ребро становится недоступным.
3. **Поиск маршрута.** Дейкстра по полученным весам; найденный маршрут помечает свои рёбра своим типом кабеля, что влияет на прокладку следующих кабелей.

Результат зависит от порядка прокладки — порядок задаётся пользователем (в проекте: сначала силовые магистрали, затем шины данных, затем сигнальные цепи).

Для каждого кабеля программа дополнительно считает маршрут без ограничений и маршрут только с учётом зон, поэтому в журнале видно, чем вызвано удлинение: обходом зоны, требованиями ЭМС или совместной прокладкой.

## Возможности

- Редактирование всех исходных данных в таблицах: узлы, рёбра, запрещённые зоны, блоки, соединения, матрица норм ЭМС; порядок прокладки меняется кнопками.
- **Схема трассировки**: каркас отсеков, зоны, удалённые узлы и цветные маршруты кабелей. Вращение левой кнопкой мыши, масштаб колесом, готовые ракурсы (объёмный, сверху, сбоку, спереди), галочки «что показывать».
- **Кабельный журнал** и спецификация по типам кабелей с суммарными длинами.
- **Протокол алгоритма**: пересчёт весов по ЭМС и пошаговая трасса Дейкстры для каждого кабеля — удобно для проверки расчёта вручную.
- **БД SQLite**: сохранение и загрузка проекта вместе с результатами трассировки; экспорт журнала в CSV и протокола в TXT.

## Запуск

Нужен **.NET 8 SDK** (или Visual Studio 2022 17.8+ с нагрузкой «Разработка классических приложений .NET»).

```bash
git clone <URL этого репозитория>
cd CableRouting
dotnet run
```

В Visual Studio: **Файл → Открыть → Проект или решение** → `CableRouting.csproj` → F5.

Сборка .exe:

```bash
dotnet publish -c Release -r win-x64 --self-contained false
```

При первой сборке нужен интернет — восстанавливается пакет `Microsoft.Data.Sqlite`.

## Структура БД

`проект`, `узел_маршрутной_сети`, `ребро_маршрутной_сети`, `запрещённая_зона`, `блок`, `блок_в_проекте`, `тип_кабеля`, `требования_эмс`, `требуемое_соединение` — исходные данные; `кабель` и `сегмент_маршрута` — результаты трассировки. Схема в третьей нормальной форме, целостность поддерживается внешними ключами. Один файл БД = один проект.

## Ограничения

- Маршруты ищутся жадно, по одному кабелю за раз, поэтому результат зависит от порядка прокладки и в общем случае не является глобальным оптимумом.
- Требования ЭМС учитываются по факту «занято / не занято ребро», без расчёта фактических зазоров внутри канала.
- Не учитываются радиусы изгиба, диаметры и масса жгутов, ёмкость каналов, температурные ограничения.
- Интерфейс только под Windows (Windows Forms).
